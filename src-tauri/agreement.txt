2. HIGH-PERFORMANCE ARCHITECTURE & OPERATING PARAMETERS
--------------------------------------------------------------------------------
CP is a native Windows desktop utility engineered to maximize file transfer
throughput. To achieve high operational efficiency, the Software utilizes native
Windows desktop facilities, including:
  * Win32 Asynchronous I/O Completion Ports (IOCP)
  * Direct storage subsystem read/write pipeline operations
  * Multi-threaded concurrent processing queues
  * Low-overhead Win32 WH_KEYBOARD_LL low-latency clipboard capture
  * High-throughput sector-aligned streaming pipelines

The Software operates within standard Windows operating system security boundaries
and executes according to the physical throughput and manufacturer capabilities of
your system's connected storage media, bus controllers, and system resources.
